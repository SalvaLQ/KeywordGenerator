# 🔤 SuperKeywordGenerator

A cross-platform desktop application built with **Avalonia UI** and **.NET Core** that helps you **generate keyword ideas** based on any topic or seed phrase you provide.  

The app is designed for marketers, content creators, and SEO professionals who need quick, structured keyword suggestions without relying on paid APIs.

---

## 🚀 Features

- Clean, modern, and responsive user interface (Avalonia UI).  
- Generates related keyword ideas from a single seed topic.  
- Uses smart combinations, synonyms, and Google-style suggestions.  
- Supports multi-language keyword generation.  
- Optional export to **CSV** or **JSON**.  
- Runs on **Windows**, **Linux**, and **macOS**.

---

## 🛠️ Tech Stack

- **.NET 9 / .NET Core**
- **Avalonia UI**
